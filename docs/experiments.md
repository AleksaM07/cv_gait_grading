# Experiments

Implemented smoke experiments:

- synthetic sanity check with controlled sliding, asymmetry, jitter, hopping,
  micro-stepping, command ignoring, and falls;
- grouped checkpoint-style split;
- classical flow/PCA feature extraction;
- Ridge-style score prediction;
- degradation helper functions for future robustness tests.

Planned full MuJoCo experiments require rendered rollout clips from the walker
repository.
